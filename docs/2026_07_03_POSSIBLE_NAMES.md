# Possible names for "Weave" (parked — decide later)

**Status:** TABLED 2026-07-03. "Weave" is an internal working name — it's a
crowded term (Weaveworks/GitOps-Flux, W&B Weave, Weave social, others), so it
likely gets renamed. No decision forced; the blog + code ship under "weave" for
now and rename when a name earns it. This doc holds the field so we don't
re-derive it.

**The naming brief:** the value isn't the threads (turns) — it's the *relationships
between* them. So we want a word about the **space between woven threads**, the
**visual quality of cloth/thread**, or a **graph-like textile pattern / loom
process** — anything but another "Weave."

## Rob's current lean (if forced): SHEEN
His reasoning, worth preserving because it has private roots (a name sticks when
it does): sheen = the gleam/shine off the cloth · sounds like **machine** ·
sounds a bit like **shear** → which evokes **glean** → which evokes **GLiNER**
(the NER model family in the stack). "machSheen" is a candidate wordmark. Not
final — "I'm not sure" — but the frontrunner. Also warm to: **argyle**,
**selvage**, and **ravel** (the late favorite — "maybe that's a winner").

## SG's favorites (top 4, my ranking)
| Name | Meaning | The hook | Watch-out |
|---|---|---|---|
| **Moire** (moiré) | The shimmer where two woven layers overlap | An *interference pattern* — meaning emerging where signals cross, in neither layer alone. Literally the annotation-layer-over-spine + the semantic-wave thesis. | the accent; some read it as a screen artifact |
| **Sheen** | Soft gleam of woven cloth | Most ownable; Rob's lean; the machine/shear/glean/GLiNER chain | pure surface — no graph meaning |
| **Lattice** | A crossweave that's ALSO the math term for a graph-like ordered structure | The only word natively *both* textile and graph — truest "tartan but more graph" | some software usage — needs availability check |
| **Skein** | A coil of raw yarn *before* it's woven | = the raw transcript before the engine shapes it | pronunciation not obvious; more "raw input" than "the graph" |

## The full field, by vein

### Radiance / visual quality of cloth & text
- **Sheen** — soft gleam; ownable; Rob's lean (see chain above)
- **Lustre / Luster** — the radiance of silk; Rob liked it but it fights the Lustre filesystem
- **Gloss** — surface shine AND "a gloss on a text" = an annotation (double-meaning is dead-on; but common word)
- **Chatoyance / chatoyancy** — cat's-eye shimmer that *changes with viewing angle*; literally the wave/angle thesis (same turns, different signal per reader's lens); rare, unclaimed — but hard to spell/say cold
- **Moire** — see top-4 (also fits "graph pattern from crossing")

### Graph-like textile pattern (the "tartan but more graph" ask)
- **Lattice** — see top-4; the dual textile+graph citizen
- **Reticule / reticulate** — "formed into a net/network" = literally "made into a graph"; elegant, obscure; reticule↔reticle confusion
- **Damask** — a pattern that emerges from the weave's own structure (figure from ground, same threads); Rob: "damask is nice"; but well-known fabric name, less ownable
- **Argyle** — a literal lattice of diamonds + overlaid diagonal = a graph in wool; Rob likes it; but reads "socks/sweaters"

### Loom tools & processes (the "tools that shape fabric" ask)
- **Ravel** — a CONTRONYM: means both tangle AND untangle ("unravel a conversation" = the read direction); short, intriguing; Rob's late favorite ("maybe that's a winner")
- **Selvage / selvedge** — the self-finished edge that keeps cloth from unraveling (the structural edge holding it together); Rob likes it; "salvage" collision when spoken
- **Heddle** — the loom part that lifts/separates warp threads to make the shed (imposes structure on raw threads); obscure, characterful
- **Reed** — the comb that sets thread spacing + beats the weft in; short but reads as plant/instrument
- **Shed** — the loom's *temporary* opening that exists only during weaving, then closes into cloth (poetic: meaning as a transient opening); collides hard with "garden shed"
- **Warp / Weft** — the two thread axes (warp = the taut spine = reply-to chain; weft = woven across = the annotation layer). Conceptually perfect BUT **ruled out — too crowded** (Rob: "probably 1000000 projects," other Claudes flagged it too)

## Process note for whoever picks
Before committing to ANY of these, run an availability pass — GitHub org,
crates.io, npm, domain, a quick trademark sense — so we don't rename into another
crowded name (the whole reason we're leaving "weave"). SG offered; not yet run.
Identity is the highest-collision namespace — check the instance, don't trust the
name feeling free. [[2026-06-10-instance-test-hardest-on-identity]]
